Track 08 · macOS app

DeskStatus

Looking can't turn into doing by accident.

Dozens of daemons, paper books and research jobs each write their own state. DeskStatus puts all of it in one window and one menu-bar light, and it can't sign anything.

TRACK 08
7keyboard tabs: floor, engines, Hyperliquid, paper, printer, sleeve, Apex
1 spolling for live state; Apex every 3 s; health check every 60 s
0keys opened. The only action writes an intent file for a separate signer

How it works

Daemons and jobs write JSON and JSONL snapshots, pid files and heartbeats. DeskStatus reads them and shows the whole desk at once. A staleness state machine makes old data read as old instead of as calm.

The one action is SELL ALL → CONFIRM, two steps. It writes an intent file and wakes a separate signer over a Unix socket. The app itself never opens a key.

What's in it

  • Seven keyboard tabs, from the live floor to the Apex platform
  • A menu-bar extra with a coloured status dot, visible from any app
  • Headless modes: --screenshot renders the dashboard at 2×, --dump --text prints the floor for scripts
  • Shipped as v1.0.3

The real window shows live account data, so it isn't pictured here.
