The rig

backtesting infrastructure · python

Four rules, enforced by the code rather than my good intentions:

  • Every idea is written down before any data is touched, in a log where editing an old entry breaks the chain.
  • The multiple-testing correction is applied automatically, every time results are read — so a failure from months ago still counts against a claim I make today.
  • The final test period is sealed. One attempt per idea, and the attempt is recorded before the test runs — so a crash still uses it up.
  • Parameter fishing is refused. Three versions of an idea count as three tests.

Ninety ideas went through it. None survived — written up as 90 Hypotheses, Zero Edges (pdf).

Two things that failed usefully

the bot, and the tool that won't answer

A trading bot. Its backtests looked wonderful because I had assumed prices I could not really trade at. Recalculated honestly, the profit vanished. I retired it and turned each lesson into a rule in the rig above.

An ETF cost comparison. It ranks nothing on purpose: two cost components are not available free, so ranking would just promote whichever fund has the least data. It reports what is missing instead.
